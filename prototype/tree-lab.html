SHARED DRAWING TOOLS
Component editor


Left-drag paints; right-drag temporarily erases. Pixel edits use the same stroke core as the main frame and climb editors.


Resize pads with transparent cells. Cropping painted cells is refused; move guides or erase unwanted pixels first. A recovery copy is kept.
Pixels and affordances are independent. Painting a roof does not invent a standing span; erasing artwork does not silently move sockets. Near/far marks affect depth metadata, never the material colour.


Choose a socket, then click its new position with the Socket point layer. Incoming sockets attach this component; outgoing sockets accept the listed child kinds.


Connection & contact geometry
Editable cell coordinates. Sockets have id, x/y, in/out direction, pillar/toy type and accepted child kinds. Standing spans use x1/x2/y; grips use x1/x2/y1/y2, material and sides. Invalid edits stay in this box until corrected.


Save, compare and recover
Edits are saved to a separate browser outbox for this tab, then autosaved to disk with an exact version hash. Disk saves join the Studio asset-change journal as tree drafts; no integration receipt is completed.
Loading/importing retains a recovery copy first. A stale tab cannot overwrite a newer disk version. If disconnected, export your draft or retry saving when the lab server returns.
